# bounce_bames

[電気通信大学プログラミング教室](https://www.uec-programming.com)の教材として作成した，原始的な玉打ちゲームです．

## ゲームの起動方法

ターミナルで下記のコマンドを入力すると、ウィンドウが開いてゲームが始まります。  
仮想環境などを入れている場合は適宜コマンドを変えてください。

```python
python bounce1.py
```

ゲームが終了するとプログラムは自動で終了します。

## 操作方法

バーの移動: 左右キー

## ゲーム紹介

### bounce1.py 玉打ちゲーム

画面下のバーを動かして、玉を打ち返します。  
玉が画面下に落ちたらゲームオーバーです。  
bounce2.py, bounce3.py の基となっています。

### bounce2.py テニスゲーム

画面上のCOMプレイヤーと玉を打ち合います。

### bounce3.py ブロック崩し

玉を打ち返して画面上部のブロックを壊します。  
全てのブロックを壊したらクリア。  
玉を画面下に落としたらゲームオーバーです。
